I Built a CAPTCHA That Uses Taiwan's Bopomofo Alphabet — Bots Can't Read It, Taiwanese Users Type It Instantly

Swapping the alphanumerics in a CAPTCHA for ㄅㄆㄇㄈ: less familiar to OCR bots, zero friction for anyone with a Zhuyin keyboard. Published as hengineer/bopomofo-captcha for Laravel, MIT-licensed.

Why Bopomofo

Traditional CAPTCHAs use Latin letters and digits — exactly what cracking tools are trained on. Bopomofo (ㄅㄆㄇㄈ, the 37 characters at Unicode U+3105–U+3129) shows up far less in general OCR training data. Meanwhile, for a Taiwanese user, seeing ㄍㄨㄟ and typing it back on a Zhuyin keyboard is faster than deciphering warped English letters. That's a rare combination: harder for the attacker, easier for the user.

The package is adapted from the well-known mews/captcha, with the whole pipeline reworked for multi-byte Bopomofo input, plus single-use validation, timing-leak protection, and per-route throttling.

Two modes

Session mode — for classic form-based sites. One helper renders the image in Blade, one validation rule checks it:

{!! bopomofo_captcha_img() !!}
<input name="captcha" placeholder="Type the symbols above with a Zhuyin IME">

$request->validate([
    'captcha' => 'required|bopomofo_captcha',
]);

Stateless API mode — for SPAs and mobile clients. Fetch a JSON endpoint for a key and a base64 image, then send the key back when validating:

GET /bopomofo-captcha/api/default
→ { "key": "bopomofo_captcha_xxx", "img": "data:image/png;base64,…" }

$request->validate([
    'captcha' => 'required|bopomofo_captcha_api:' . $request->input('key'),
]);

Security design

  • No plaintext answers — the solution is bcrypt-hashed into the session (or cache, in API mode); the server never stores it readable.
  • Single use — a successful check immediately destroys the record, so an image can't be replayed.
  • Timing-leak protection — check_api() compares on a constant-time path, giving attackers no timing signal.
  • Route throttling — the image endpoints ship with built-in rate limiting against brute-force harvesting.

What you can tune

Four ready-made profiles — default, flat, mini, inverse — each overriding length, dimensions, noise lines, rotation, contrast, sharpen, blur, invert, expiry, and more. Fonts aren't hard-wired: to stay lightweight the package ships without one, and any CJK TTF/OTF covering the Bopomofo block works (Noto Sans TC, Source Han Sans, and jf-openhuninn are all free under SIL OFL). To go really small, subset a full font down to just the 37 glyphs:

pyftsubset NotoSansTC-Regular.otf \
    --unicodes=U+3105-3129 \
    --output-file=NotoSansTC-Bopomofo.ttf

Getting started

composer require hengineer/bopomofo-captcha

Requirements: PHP 8.1+, Laravel 10/11/12, and the gd / mbstring / fileinfo extensions. There's also a complete Docker demo project — docker compose up -d gives you both session and API modes to play with locally.
