我做了一個「注音符號驗證碼」Laravel 套件——機器人看不懂，台灣人秒懂

把驗證碼的英數字換成 ㄅㄆㄇㄈ：對 OCR 機器人更陌生、對用注音輸入法的台灣使用者零負擔。套件名稱 hengineer/bopomofo-captcha，MIT 開源。

為什麼是注音

傳統驗證碼用英數字，但破解工具也都是針對英數字訓練的。注音符號（ㄅㄆㄇㄈ，Unicode U+3105–U+3129 共 37 個字元）在通用 OCR 的訓練資料裡少見得多；而對台灣使用者來說，看到 ㄍㄨㄟ 直接用注音鍵盤打回去，比辨認扭曲的英文字母還快。這是一個「攻擊者更難、使用者更簡單」的少見組合。

套件改寫自知名的 mews/captcha，把整條管線換成多 byte 的注音字元，並加上一次性驗證、時序洩漏防護與路由級流量限制。

兩種使用模式

Session 模式——傳統表單網站用。Blade 裡放一行 helper 產生圖片，validation rule 直接驗：

{!! bopomofo_captcha_img() !!}
<input name="captcha" placeholder="請用注音輸入法輸入上方符號">

$request->validate([
    'captcha' => 'required|bopomofo_captcha',
]);

無狀態 API 模式——給 SPA 或行動端。先打 JSON 端點拿 key 和 base64 圖片，驗證時把 key 一起送回：

GET /bopomofo-captcha/api/default
→ { "key": "bopomofo_captcha_xxx", "img": "data:image/png;base64,…" }

$request->validate([
    'captcha' => 'required|bopomofo_captcha_api:' . $request->input('key'),
]);

安全設計

  • 答案不落地——正解以 bcrypt 雜湊存在 session（API 模式存 cache），伺服器端不留明文。
  • 單次使用——驗證成功立刻銷毀紀錄，同一張圖不能重放。
  • 時序洩漏防護——check_api() 的比對走恆定時間路徑，不給攻擊者計時線索。
  • 路由節流——產圖端點內建 throttle，擋暴力刷圖。

可以調整的東西

內建四組 profile：default、flat、mini、inverse，各自可覆寫長度、寬高、干擾線數量、旋轉角度、對比、銳化、模糊、反相、有效期限等參數。字型不綁死——套件為了輕量不內建字型，丟任何涵蓋注音區段的 CJK 字型進去就能用（Noto Sans TC、思源黑體、粉圓都是 SIL OFL 免費授權）。想更輕，可以用 pyftsubset 把整套字型精簡成只剩 37 個注音字元：

pyftsubset NotoSansTC-Regular.otf \
    --unicodes=U+3105-3129 \
    --output-file=NotoSansTC-Bopomofo.ttf

怎麼開始

composer require hengineer/bopomofo-captcha

需求：PHP 8.1+、Laravel 10/11/12、gd／mbstring／fileinfo 擴充模組。也有一個完整的 Docker demo 專案，docker compose up -d 就能在本機玩到 session 和 API 兩種模式。
